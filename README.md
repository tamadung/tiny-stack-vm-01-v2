# tiny-stack-vm-01

A faithful, compact interpreter of make.fun's tiny stack ISA (v1): 32-bit wrapping integers, a 256-value stack, branches, calls, 256 words of memory, input/output, and all ten traps with their own exit codes. One run answers all 40 instances of a set in well under the 60-second budget. Practice set score: 1,000,000 / 1,000,000.
